# Claude + Google Drive MCP: สกัดข้อมูลใบเสร็จอัตโนมัติด้วย AI

หนึ่งใน Use-Case ที่ผู้ประกอบการและสำนักงานบัญชี **ขอใช้งานเยอะที่สุด** คือการจัดระเบียบเอกสารกองโต — ใบเสร็จ ใบกำกับภาษี ใบเสนอราคา และใบแจ้งหนี้ที่ทยอยเข้ามาทุกวัน

บทความนี้จะพาไปดูวิธีต่อ **Model Context Protocol (MCP)** เชื่อม Claude เข้ากับ Google Drive เพื่อสร้าง Automation Engine ที่สกัดข้อมูลจากเอกสารบัญชีแบบ end-to-end — ตั้งแต่ดึงไฟล์จาก Drive อ่านด้วย Claude Vision ส่งผลเข้า Excel/PEAK/Flow Account โดยแทบไม่ต้องคีย์มือเลย

## ปัญหาในการจัดการเอกสารบัญชีแบบเดิม

เอกสารบัญชีที่ไหลเข้ามาทุกวันมักมีปัญหาหลักอยู่ 2 รูปแบบ คือ **เอกสาร hard copy** ที่ต้องสแกนหรือถ่ายรูปก่อน และ **ไฟล์ PDF หรือรูปภาพ** ที่กระจัดกระจายไม่ได้จัดเป็นระเบียบบน Google Drive

ผลลัพธ์คือนักบัญชีต้องเสียเวลามากกับงานคีย์ข้อมูลซ้ำๆ ซึ่งทั้งช้า เสี่ยงพิมพ์ผิด และไม่สร้างคุณค่าให้ธุรกิจ

ปัญหาที่พบบ่อยจากการบันทึกบัญชีแบบ manual:

- **ใช้เวลามาก** — บันทึกรายการด้วยมือใช้เวลานานและเสี่ยงผิดพลาด
- **ข้อมูลไม่ Real-time** — ผู้บริหารไม่เห็นภาพรวมทางการเงินได้ทันที
- **ตรวจสอบยาก** — เอกสารกระจัดกระจาย ติดตามและ audit ไม่สะดวก

> 💡 เวลาที่เสียไปกับการคีย์ใบเสร็จ ถ้าเอาไปคิดงานเชิงวิเคราะห์หรือบริการลูกค้า จะสร้างมูลค่าได้มากกว่ามาก

## ทางออก: Claude + Google Drive MCP = Automation Engine

แนวคิดของ Invoice Automation Workflow ที่เราจะใช้คือการประกอบความสามารถ 2 อย่างของ Claude เข้าด้วยกัน

ส่วนแรกคือ **MCP Connector สำหรับ Google Drive** ที่ทำให้ Claude สามารถเข้าไปอ่าน เขียน และจัดการไฟล์ในโฟลเดอร์ Drive ของเราได้โดยตรง เปรียบเสมือนให้ Claude มีกุญแจเข้า Drive แทนเรา

ส่วนที่สองคือ **Claude Vision** ซึ่งเป็น vLLM (Vision Language Model) ที่อ่านรูปและตารางในเอกสารได้แม่นยำ เข้าใจโครงสร้างใบกำกับภาษีหรือใบเสร็จได้โดยไม่ต้องตั้งกฎ OCR เองทีละ template

เมื่อนำสองส่วนนี้มารวมกัน ก็จะกลายเป็น **Automation Engine** ที่ทำ Data Extraction จากเอกสารบัญชีได้แบบ end-to-end

| ความสามารถ | สิ่งที่ทำได้ |
|------------|----------|
| MCP Google Drive | เข้าถึง / อ่าน / เขียนไฟล์ใน Drive ได้โดยตรง |
| Claude Vision | อ่านใบเสร็จ ใบกำกับภาษี เข้าใจตารางและตัวเลข |
| รวมกัน | สกัดข้อมูลจากเอกสารบน Drive → ส่งเข้า Excel/PEAK ได้อัตโนมัติ |

## EP2: ตั้งค่า MCP เชื่อม Claude เข้ากับ Google Drive

ขั้นตอนแรกของ workflow คือการต่อ **MCP Connector สำหรับ Google Drive** หรือที่เรียกง่ายๆ ว่า "ตัวควบคุม Google Drive" ให้ Claude ใช้งานได้

เมื่อต่อ MCP สำเร็จ Claude จะเข้าไปอ่านไฟล์ในโฟลเดอร์ Drive ของเราที่ใช้เก็บใบเสร็จและใบกำกับภาษีที่สแกนหรือถ่ายรูปไว้ได้ทันที โดยไม่ต้อง upload ไฟล์ที่ละชิ้นเข้า chat อีกต่อไป

นี่คือการเตรียมความพร้อมก่อนสกัดข้อมูลด้วย AI ใน EP ถัดไป เพื่อส่งข้อมูลปลายทางเข้า Excel, Google Sheet, PEAK Account หรือ Flow Account

## EP3: สกัดข้อมูลด้วย Claude Vision แล้วส่งเข้า Excel/PEAK/Flow Account

หลังจากต่อ MCP เรียบร้อย workflow จริงจะทำงานเป็น 4 ขั้นตอนต่อเนื่อง

1. **ดึงไฟล์** จาก Google Drive (ใบเสร็จ ใบกำกับภาษี ที่สแกนไว้)
2. **ประมวลผลผ่าน Claude Vision** เพื่อ OCR + เข้าใจโครงสร้างเอกสาร
3. **จัดข้อมูลลง Excel** ตาม template ที่กำหนด
4. **Upload ไฟล์ Excel กลับขึ้น Drive** หรือส่งต่อไปขั้นต่อ

ทำเป็น Auto ทั้งหมดก็ได้ หรือจะทำมือนิดหน่อยที่บางขั้นตอนเพื่อให้นักบัญชีตรวจสอบก่อนก็ได้

ประเด็นต่อยอดที่น่าสนใจคือ ถ้า Excel template ที่ใช้เป็นรูปแบบ **import-ready ของ PEAK หรือ Flow Account** จะ import ไฟล์เข้าโปรแกรมบัญชีได้ทันที — แปลว่านักบัญชีแทบไม่ต้องคีย์ data entry อีกต่อไป

## ประโยชน์ที่นักบัญชีจะได้

เมื่อ workflow นี้ทำงานเต็มรูปแบบ จะเปลี่ยนวิธีทำงานของนักบัญชีในหลายมิติ

### 1. จำแนกเอกสารอัตโนมัติ

Claude Vision อ่านและจำแนกประเภทเอกสารบัญชีได้ — แยก ใบเสร็จ, ใบแจ้งหนี้, ใบกำกับภาษี ออกจากกันโดยไม่ต้องมานั่งดูทีละใบ

### 2. จับคู่รายการอัตโนมัติ

นำเอาข้อมูลจากใบเสร็จไปจับคู่กับสลิปโอนเงินหรือใบวางบิลค้างจ่ายได้โดยอัตโนมัติ ลดเวลาทำ Bank Reconciliation อย่างเห็นผล

### 3. วิเคราะห์และรายงานได้ลึกขึ้น

เมื่อข้อมูลอยู่ใน Excel/PEAK เรียบร้อย Claude ยังต่อยอดวิเคราะห์ภาพรวม สร้างรายงานเชิง insight และแจ้งเตือนเมื่อพบรายการผิดปกติได้อีกชั้น
